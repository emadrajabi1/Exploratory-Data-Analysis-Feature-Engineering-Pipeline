# Exploratory Data Analysis (EDA) & Feature Engineering Pipeline

A comprehensive collection of Jupyter Notebooks and Python scripts demonstrating end-to-end data preprocessing, Exploratory Data Analysis (EDA), and advanced Feature Engineering workflows. This repository serves as a structured practice portfolio for mastering data cleaning, transformation, and preparation techniques essential for machine learning pipelines.

---

## 📂 Project Structure & Modules

The repository is organized into sequential learning and implementation modules:

### 1. Data Understanding & Inspection
* **`1_examining_data_type_structure.ipynb`**[cite: 1]: Inspecting initial data frames, data types, memory usage, and structural overviews.
* **`4_Understanding_Data_Irregularities.ipynb`**[cite: 1]: Identifying anomalies, outliers, and data quality issues.

### 2. Data Cleaning & Preprocessing
* **`2_Handling_Missing_Data.ipynb`**[cite: 1]: Strategies and implementations for detecting and imputing missing values.
* **`3_Normalization_and_Standardization.ipynb`**[cite: 1]: Feature scaling techniques to normalize and standardize numerical distributions.
* **`5_Encoding_Categorical_Variables.ipynb`**[cite: 1]: Transforming categorical features using techniques like One-Hot Encoding and Label Encoding.
* **`6_Detecting_and_Removing_Duplicates.ipynb`**[cite: 1]: Identifying and cleaning redundant duplicate records.

### 3. Feature Engineering
* **`7_Feature_Engineering_Creation.ipynb`**[cite: 1]: Domain-driven creation of new informative features.
* **`8_Feature_Engineering_Extraction.ipynb`**[cite: 1]: Extracting latent patterns and high-level representations from raw data.
* **`9_Feature_Engineering_Selection.ipynb`**[cite: 1]: Filtering relevant features to optimize model performance and prevent dimensionality curses.
